# **Dashboard Web Application**

This is a simple **Dashboard** project built using **HTML** and **CSS** only. It is a static dashboard layout designed to display various data, charts, and widgets. The project showcases a clean and modern user interface with responsive design.

---

## **Features**:

This dashboard includes the following features:

1. **Sidebar Navigation**: Allows users to navigate through different sections of the dashboard (e.g., Home, Settings, Profile, etc.).
2. **Main Dashboard Area**: Displays key information like statistics, charts, and widgets.
3. **Responsive Design**: The layout adjusts to different screen sizes, making it usable on mobile and desktop devices.
4. **Minimalistic Style**: A simple, clean, and modern design with a focus on usability.

---

## **Pages**:

1. **Home Page**: The main page that shows an overview of data with a sidebar and top navigation bar.
2. **Profile Page**: A page to display user information and profile settings.
3. **Settings Page**: A page for adjusting various settings within the dashboard.

---

## **How to Use the Dashboard**:

Since this dashboard is built using only **HTML** and **CSS**, it is **static** and doesn't have any dynamic functionality. The purpose of the dashboard is to show how to structure and style a web-based admin panel or dashboard layout.

1. **Navigate the Dashboard**: Click on the links in the sidebar to navigate between different pages (Home, Profile, Settings).
2. **View the Dashboard Widgets**: The home page contains various sections such as statistics, charts, and other data visualizations (though they are static in this case, with no interactivity).

---

## **Technologies Used**:

- **HTML**: Used to structure the content of the dashboard.
- **CSS**: Used for styling the dashboard and making it visually appealing.
- **Responsive Design**: Utilized CSS media queries to ensure the layout adapts to different screen sizes.
